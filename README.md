# java-calculator-precourse

## 입력
***
1. 입력 문구가 출력된다
    - `덧셈할 문자열을 입력해 주세요.`
2. 구분자와 양수로 구성된 문자열이 입력으로 주어진다

## 입력 검증
***
1. 다음은 사용자가 잘못된 값을 입력한 경우이다
   - 빈 문자열이 들어온 경우
   - 커스텀 구분자의 선언이 틀린 경우
   - 커스텀 구분자, 기본 구분자 이외의 특수기호가 들어온 경우
   - 음수가 들어온 경우

## 문자열 파싱
***
1. 커스텀 구분자, 기본 구분자를 이용하여 숫자를 구분한다

## 숫자 합 계산
***
1. 구분된 숫자들을 덧셈 계산한다

## 출력
***
1. 계산한 결과값이 출력된다
    - `결과 : (결과값)`
